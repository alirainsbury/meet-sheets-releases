# Meet Sheets — downloads

Download Meet Sheets from **https://laneten.app/meet-sheets/**.

This repository only holds the release files (macOS and Windows). The source code is private.

- **macOS** (Apple Silicon): `Meet-Sheets-mac.zip`, signed and notarised by Apple.
- **Windows** (10 and 11): `Meet-Sheets-windows.exe`, a single portable file with no installer.

Latest version: [Releases → Latest](https://github.com/alirainsbury/meet-sheets-releases/releases/latest)
